# Data access

The data used in this project are not publicly distributed through this repository.

## Restricted materials

The restriction covers:

- the course-provided speech corpus and country-year panel;
- restored full speech texts and row-level derived panels;
- blinded validation samples and annotation-level results;
- verbatim evidence and target spans;
- batch inputs, model responses, checkpoints, and execution logs; and
- any DVC objects or archives containing these materials.

Only code, methodological documentation, the paper, figures, and aggregate statistical results are public.

## Requesting access

Researchers who want to inspect or reproduce the restricted data should contact the repository owner through the GitHub profile associated with this repository. Please include:

1. your name and institutional affiliation;
2. the purpose of the request;
3. the specific files or level of access needed; and
4. confirmation that you will comply with the original source and course-data conditions.

Access is granted case by case. A request does not guarantee approval, and approved materials may not be redistributed.

## Reproduction after approval

The public scripts document their expected input paths. Approved users can place the supplied files in a local `data/` directory; that directory is intentionally ignored by Git. Never commit or upload the restricted files, even to a feature branch or pull request.
